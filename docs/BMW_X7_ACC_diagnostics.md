# BMW X7 G07 — поиск сигналов адаптивного круиза

## Замеры BimmerLink


| Поле | Сырое значение | Наблюдение |
| --- | --- | --- |
| Запрос системы помощи водителю — статус | 3584 / 0x0E00 | Обычное движение. То же значение наблюдалось на стоянке. |
| То же | 520 / 0x0208 | Наблюдалось при Driving Assistant Professional. |
| То же | 521 / 0x0209 | Наблюдалось при Driving Assistant Professional. |
| То же | 776 / 0x0308 | LIM, по сводке в чате. |
| Статус запроса водителя к системе помощи | 0 → 1 | Менялся при включении ассистента. Поле описывает запрос. |
| Условие круиз-контроля активно | 0 | Снимок на стоянке. |
| Круиз-контроль доступен через CAN | 255 / 0xFF | Снимок на стоянке. Значение пока не расшифровано. |
| Запрос направления движения системы помощи водителю | 0 | Снимок на стоянке. |

Разница между 520 и 521 и состояние ACC без подруливания пока не установлены. Числа в таблице — значения полей. Для чтения через диагностику ещё нужны имя блока, адрес, DID, раскладка ответа и масштаб. Для подписки из MGU нужны интерфейс, экземпляр, поле и имя члена структуры.

## Что искать в выгрузках

| Что нужно | Английские и немецкие фрагменты имён |
| --- | --- |
| Активное управление скоростью, ожидание, отмена | adaptive cruise, active cruise, cruise control, ACC, ACC status, longitudinal control, Geschwindigkeitsregelung, Abstandsregelung, Abstandsregeltempomat, Laengsregelung, Längsregelung |
| Заданная скорость круиза | set speed, target speed, desired speed, selected speed, cruise setpoint, Sollgeschwindigkeit, Wunschgeschwindigkeit, Setzgeschwindigkeit, gesetzte Geschwindigkeit |
| Отличить Professional от ACC и LIM | Driving Assistant, assisted driving, steering assistant, lane centering, DAP, Fahrerassistenz, Lenkassistent, Spurführung, Spurführungshilfe, Geschwindigkeitsbegrenzer, speed limiter, LIM |
| Дополнительные признаки ACC | distance setting, time gap, lead vehicle, Stop & Go, Abstandsstufe, Zeitlücke, Zielobjekt, Anfahren |

В каталоге MGU поискать также слитные варианты без пробелов и подчёркиваний, например `CruiseControl`, `SetSpeed`, `TargetSpeed`, `Fahrerassistenz`, `Sollgeschwindigkeit`. Это ключевые слова для поиска, точные имена полей пока не подтверждены.

## Как получить исходные файлы

1. На MGU открыть [Car Explorer](https://github.com/arefahmad/idrive7-apps#the-apps). Он читает локальный каталог SOME/IP и сохраняет `explorer-report.txt` в папке данных приложения. Взять полный отчёт. Он покажет доступные имена и способы чтения полей.
2. В BimmerLink сохранить лог или скриншоты нужного блока. По возможности включить все поля из таблицы, скорость автомобиля и показание заданной скорости на приборке. Вместе с выгрузкой сохранить название блока и единицы измерения.
3. Для сопоставления пометить время обычной езды, LIM, ACC без подруливания (если доступен), Professional и отмены круиза. В одном активном интервале отметить изменение заданной скорости. Подойдёт любой законный и безопасный для участка переход, который выполняется при обычной езде. Запись и отметки может вести пассажир.

Для графика приложения нужны отдельно **состояние активного круиза** и **заданная скорость**. Поле заданной скорости проверяется по совпадению с приборкой, в том числе когда фактическая скорость отличается. Если уставка сохраняется после отмены, график прерывается по полю активности. Быструю серию изменений на обзорном графике можно свернуть до последней уставки, сохранив исходные события с таймстемпами.

## Найденные кодировки

В локальной карте есть `LIN_VARIANTE_MFL` (`ACC`, `ACC_SLD`, `ACC_STA_SLD` и другие варианты) и `WARNSTUFE_ACC_STOP_AND_GO`. Они относятся к конфигурации и сами по себе не дают статус и скорость во время поездки.
